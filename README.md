# Dalia Ontology



## Getting started

The Ontology is in Work packages 11 and 12 in the project proposal. Initial draft based on the six use cases in the proposal and EduCor.

- Added RDMTool class so that researchers can add their RDM tools to the platform and make it available to others.
- Added Job class and relations with Skill class (essentialFor and optionalFor)

## Patterns
- A RDM pattern
- B Educational resource pattern
- C Skill pattern
- D Learning path pattern
- E Recommendation pattern
- F User profile pattern
- G Assessment pattern
- H User enrollment pattern
- I User role pattern
- J Community pattern
